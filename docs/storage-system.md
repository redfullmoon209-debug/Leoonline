# Leoonline — Storage / คลังเก็บของ

## UI ที่ใช้งานจริง

- **ปุ่มกระเป๋าบน HUD เหลือเพียงปุ่มเดียว** เปิดหน้ากระเป๋า Inventory ได้ตามเดิมทั้ง PC และมือถือ
- บนแถบเมนูหลักมี **5 ปุ่มขนาดเท่ากันและจัดกลาง**: กระเป๋า / ตัวละคร / สกิล / ร้านค้า / **คลังเก็บของ**; ใช้ PNG หีบเดิมและข้อความที่แปลภาษาได้ ไม่มีไอคอนคลังแยกบน HUD
- กดแท็บ **คลังเก็บของ** เพื่อดูคลังซ้าย–กระเป๋าขวา แล้วเลือกแท็บย่อย **ไอเทม** หรือ **เงิน** บนฝั่งคลัง
- เปิดคลัง: **คลังเก็บของฝั่งซ้ายแทน Equipment** และ **กระเป๋าผู้เล่นเดิมฝั่งขวา** พร้อมเงิน 4 ประเภท ไม่เคลื่อนกระเป๋าไปฝั่งซ้ายเหมือน Shop
- UI แดงเข้ม–ทองใช้ PNG กรอบและช่องที่มีอยู่แล้วจาก `assets/ui/red_matte/` และ `assets/ui/inventory/`; ช่องไอเทมไม่มีข้อความฝังใน PNG
- คลังเก็บได้ **200 ช่อง** แบ่งเป็น **4 หน้า หน้าละ 50 ช่อง (10×5)** เปิดใช้ได้ครบ 200 ช่องตั้งแต่เริ่มต้น ไม่มีการคิดเงินหรือขยายคลัง ณ เวอร์ชันนี้
- กระเป๋าผู้เล่นยังมี **200 ช่อง แต่ปลดล็อกเริ่มต้น 40 ช่อง** เหมือนเดิม
- คลิกไอเทมในกระเป๋าขวาแล้วกด **ฝากของ** เพื่อย้ายเข้าคลังซ้าย
- คลิกไอเทมในคลังซ้ายแล้วกด **ถอนของ** เพื่อย้ายกลับกระเป๋าขวา
- ฝาก–ถอนเป็น **การย้ายของจริง** ไม่ใช่การคัดลอกไอเทม; ของถูกลบจากต้นทางและเพิ่มที่ปลายทางเพียงรายการเดียว
- ฝั่งคลังมีปุ่มเปลี่ยนหน้าไปหน้าแรก/ก่อนหน้า/ถัดไป/สุดท้าย มีรายละเอียดไอเทมเมื่อแตะ/คลิก
- **5 แท็บบนสุด** เท่ากันและสมดุลซ้ายขวา; 4 เมนูเดิมยังอยู่ พร้อมแท็บคลัง ส่วนปุ่มล่าง 6 ปุ่มยังเหมือนเดิม กด Inventory จะกลับหน้าสวมใส่+กระเป๋าปกติ และ Shop ยังคงแสดงกระเป๋าซ้าย/ร้านค้าขวาตามเดิม
- **คลังเงิน 4 สกุล**: ทอง เพชรฟ้า เพชรม่วง และเพชรเขียว แต่ละสกุลมี *ยอดในกระเป๋า* กับ *ยอดในคลัง* แยกกัน ไม่แลกเปลี่ยนสกุลอัตโนมัติ
- ในแท็บย่อยเงิน เลือกสกุล กรอกจำนวนเป็นตัวเลข จากนั้นกด **ฝากเงิน** หรือ **ถอนเงิน**; มีปุ่ม **ทั้งหมดในกระเป๋า** และ **ทั้งหมดในคลัง** เพื่อกรอกจำนวนเต็มทันที
- จำนวนเงินทั้งในกระเป๋าและคลังแยกประเภท รองรับจำนวนสูงสุด **999,999,999,999,999,999,999 (21 หลัก)** โดยเก็บเป็น String และใช้การบวก/ลบจำนวนเต็มแบบข้อความทั้งหมด ไม่มีความคลาดเคลื่อนจาก float/JavaScript Number

| ไฟล์ | หน้าที่ |

## ความปลอดภัยข้อมูล / หลักการแลกเปลี่ยน

- ทั้งกระเป๋าและคลังบันทึกใน **Save ก้อนเดียวกัน** ภายใต้คีย์ `slots`, `storage_slots`, `currency`, `storage_currency` โดยไฟล์ `user://leoonline.json` และ localStorage บนเว็บ
- ฝาก/ถอนเงินหักยอดต้นทางและเพิ่มยอดปลายทางเพียงครั้งเดียว ตรวจจำนวนเงินไม่เกิน 21 หลัก, ห้ามเป็น 0/ติดลบ/ทศนิยม/ตัวอักษร, ตรวจเงินต้นทางและเพดานปลายทางก่อนเปลี่ยนเงิน และ rollback สองฝั่งเมื่อบันทึกล้มเหลว
- เซฟเก่าที่ไม่มี `storage_currency` โหลดได้โดยเริ่มเงินในคลังทั้ง 4 ประเภทเป็นศูนย์ โดยไม่ลบเงินในกระเป๋าเดิม
- การโอนตรวจพื้นที่ว่างของปลายทางก่อนแก้ข้อมูล โดยถอนจากคลังจะวางได้เฉพาะช่องที่ปลดล็อกแล้วในกระเป๋า
- บันทึกผิดพลาดจะย้อนข้อมูลสองฝั่งกลับ ไม่มีการย้ายสำเร็จครึ่งเดียว
- บันทึกเกมรุ่นเก่าที่ไม่มี `storage_slots` เปิดได้โดยเริ่มคลังว่างเปล่า ไม่ลบกระเป๋า/เงินเดิม
- **สำคัญ:** ตอนนี้ Save อยู่ในเบราว์เซอร์ของผู้เล่น ไม่ใช่เซิร์ฟเวอร์ จึงยังไม่ใช่คลังร่วมบัญชีข้ามอุปกรณ์หรือคลังออนไลน์ที่ป้องกันโกง เมื่อเพิ่มระบบล็อกอิน/Multiplayer ต้องย้ายธุรกรรมและตรวจการฝาก–ถอนไปเซิร์ฟเวอร์แบบ atomic

## วิธีทดสอบ

1. เปิด https://redfullmoon209-debug.github.io/Leoonline/ และรีโหลดเวอร์ชันล่าสุด
2. กดไอคอน **กระเป๋า** มุมขวาบน แล้วกดแท็บที่ 5 **คลังเก็บของ** บนแถบบน
3. ตรวจว่าซ้ายเป็นช่องคลัง 50 ช่องและขวาเป็นกระเป๋าเดิม พร้อมเงิน
4. กด Demo Items เพื่อรับไอเทมทดสอบ แล้วกดไอเทมในกระเป๋าขวา → **ฝากของ**
5. ตรวจว่าไอเทมหายจากกระเป๋าขวาและปรากฏช่องแรกในคลังซ้าย
6. รีโหลดหน้าเว็บ เปิดคลังอีกครั้ง ตรวจว่ายังมีของที่ฝาก
7. กดไอเทมในคลังซ้าย → **ถอนของ** ตรวจว่าไปอยู่กระเป๋าขวาโดยไม่มีของซ้ำ
8. เปิดแท็บย่อย **เงิน** ทางซ้าย เลือกทองหรือเพชรชนิดใดชนิดหนึ่ง กรอกจำนวน กดฝาก ตรวจว่ายอดในกระเป๋าลดลงและในคลังเพิ่มขึ้น
9. รีโหลดเว็บ เปิดคลัง/เงิน ตรวจยอดเดิม แล้วถอนคืนและตรวจว่าไม่มีเงินซ้ำ จากนั้นทดลองแต่ละสกุล
10. สลับหน้า Inventory / Character / Shop / Skill ตรวจว่าปุ่มและระบบเดิมยังอยู่

**ข้อจำกัด:** ไอเทมในคลังยังเป็นช่องละ 1 ชิ้นตามระบบ Item ID เดิม ไม่มีสแต็ก, ค้นหา, กรอง หรือคลังออนไลน์ร่วมบัญชีในเวอร์ชันนี้
